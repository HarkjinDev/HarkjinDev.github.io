2. IPSec (Internet Protocol Security)

  • 정의: IP 계층에서 패킷의 인증·암호화·무결성을 보장하는 표준 보안 프로토콜 모음
  • 키워드: RFC2401, AH, ESP, IKE, ISAKMP, SA, SP/SPD, 전송 모드, 터널 모드, 암호화, 무결성, VPN 핵심 프로토콜
  • 분류: VPN
  • 핵심 구성 프로토콜:
    구분구성요소핵심 기술
    모드전송 모드 (Transport) - 단말간 통신페이로드만 암호화, 원본 IP 헤더 유지
    터널 모드 (Tunnel) - 게이트웨이 간 통신전체 패킷 암호화 후 새 IP 헤더 추가
    인증AH (Authentication Header)패킷 출처 인증·무결성 보장, 암호화 미제공
    ESP (Encapsulating Security Payload)페이로드 암호화·인증·무결성 동시 제공
    키 관리IKE (Internet Key Exchange)SA 협상·세션키 자동 교환·갱신
    ISAKMP(Key Management Protocol)키 교환 공통적 구조와 메시지 형식
    정책SA (Security Association)통신 양단 간 보안 파라미터 협약 단방향 연결
    SP / SPD (Security Policy)IPSec 적용 여부 정의한 규칙 및 DB
  • 동작 모드:
    항목전송 모드 (Transport)터널 모드 (Tunnel)
    암호화 범위페이로드만 암호화전체 패킷 암호화
    IP 헤더원본 IP 헤더 유지새 IP 헤더 추가
    주요 용도단말 간 직접 통신게이트웨이 간 VPN
    적용 환경Host-to-HostSite-to-Site VPN
  • AH vs ESP 비교:
    항목AHESP
    암호화❌✅
    인증·무결성✅✅
    IP 헤더 보호✅ 포함❌ 미포함
    NAT 통과❌ 불가✅ NAT-T 지원
    실무 사용드묾✅ 주로 사용
  • 인사이트: IPSec은 VPN의 핵심 암호화 인프라로 네트워크 계층에서 투명하게 동작하는 강점이 있으나, NAT 환경에서의 AH 비호환·복잡한 설정 구조로 인해 경량·고성능의 WireGuard가 대안으로 부상하고 있으며 ESP+터널 모드 조합이 실무 표준으로 자리잡고 있음
