4. SDDC(소프트웨어 정의 데이터센터, Software Defined Data Center)

  • 정의: 데이터센터의 컴퓨팅/스토리지/네트워크를 소프트웨어로 추상화하여 자동화정책 통해 통합 관리하는 인프라 아키텍처
  • 분류: 네트워크
  • 설계 핵심: 추상화, 풀링(동적 할당), 자동화, 정책 기반(Policy-driven)
  • SDDC 구성요소:
    구분추상화 대상핵심 기능
    SW Defined ComputeCPU/메모리VM 생성, 마이그레이션, 자원 통합
    SDS(스토리지)디스크/저장소논리 스토리지, Scale-out 확장
    SDN(네트워크)스위치/라우팅제어/데이터 평면, 오버레이, 마이크로세그멘테이션
    관리 계층전계층 통합자동화, 오케스트레이션, 모니터링, 셀프 서비스, 카탈로그
