[하위] 5-1. 슬라이딩 윈도우 (Sliding Window)

  • 정의: 수신 윈도우 크기만큼 ACK 대기 없이 연속 전송하여 송신량을 동적으로 조절하는 기법
  • 키워드: 윈도우 크기, ACK, 흐름 제어, 버퍼, 수신 윈도우(rwnd), 송신 윈도우
  • 분류: 네트워크 기초
  • 구성요소:
    구분구성요소핵심 설명
    윈도우윈도우(Window)ACK 대기 없이 전송 가능한 데이터 영역
    수신 윈도우(rwnd)수신 버퍼 여유 공간
    혼잡 윈도우(cwnd)네트워크 혼잡 기반 제한
    윈도우 크기min(rwnd, cwnd), 실제 송신 가능 범위 결정
    동작윈도우 열림(Sliding)ACK 수신 → 확인된 데이터만큼 윈도우 이동 → 새로운 전송 공간 확보
    윈도우 닫힘데이터 전송 → 전송 가능한 영역 감소
    윈도우 축소수신 버퍼 감소 시 rwnd 축소 → 추가 전송량 감소
    Zero Windowrwnd=0 수신 시 전송 중단·Window Probe 주기 전송
  • 동작 원리:
    단계설명핵심
    1. 윈도우 설정수신측(rwnd) 기반으로 송신 가능 범위 결정전송 범위 설정
    2. 연속 전송ACK 대기 없이 윈도우 크기만큼 데이터 연속 전송연속 전송
    3. ACK 수신수신측이 정상 수신 확인 후 ACK + 최신 rwnd 전송수신 확인·갱신
    4. 윈도우 슬라이드ACK로 확인된 데이터만큼 윈도우를 오른쪽으로 이동전송 영역 이동
    5. 윈도우 축소수신 버퍼 감소 시 rwnd 축소 → 추가 전송량 감소송신량 조절
    6. Zero Windowrwnd=0 수신 시 전송 중단·Window Probe 주기 전송교착 방지
    7. 전송 재개수신 버퍼 여유 확보 후 rwnd 갱신 → 전송 재개전송 복구
  • 인사이트: 슬라이딩 윈도우는 흐름 제어의 핵심 메커니즘이며, TCP에서는 수신 윈도우(rwnd)와 혼잡 윈도우(cwnd)의 최솟값으로 실효 윈도우를 결정. Zero Window Probe로 rwnd=0 교착 상태 해소.
