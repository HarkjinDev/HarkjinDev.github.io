6. 데이터 프로파일링 (Data Profiling)

  • 정의: 데이터의 구조, 값, 관계를 분석하여 품질 이슈를 사전에 진단하는 기법
  • 키워드: 값/구조/관계 분석, 이상값, 결측값, 참조 무결성, 데이터 품질 진단
  • 분류: 데이터 거버넌스/품질/보안
  • 품질관리 관계:
    • 수집 → 데이터 프로파일링 → 오류/품질 문제 식별 → 데이터 클리닝 → 품질 검증 → 정제 데이터
  • 수행 시점: 데이터 마이그레이션 前, 데이터 웨어하우스 구축 前, 정기 품질 점검 시
  • 주요 분석 유형:
    구분분석 내용예시
    구조 분석데이터 구조·스키마 파악(스키마 불일치 탐지)테이블, 컬럼, 데이터 타입
    내용 분석실제 데이터 값 분석(이상값/결측치 탐지)NULL 비율, 중복, 이상값
    통계 분석데이터 분포·패턴 분석최소/최대/평균, 빈도수, 평균/분산
    품질 분석데이터 품질 문제 탐지정확성, 완전성, 일관성
    관계 분석데이터 간 연관관계 파악(정합성 검증)무결성, 중복데이터, PK/FK, 참조관계
  • 인사이트: 데이터 마이그레이션 전 프로파일링을 통해 품질 이슈를 사전에 탐지하면 마이그레이션 실패 위험을 대폭 낮출 수 있으며, 프로파일링 결과는 데이터 표준화·정제 우선순위 결정의 근거 자료로 활용됨
