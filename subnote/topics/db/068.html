7. 시계열 데이터베이스(TSDB, Time Series DB)

  • 정의: 시간에 따라 지속적으로 발생하는 데이터를 타임스탬프(Time Stamp)를 중심으로 저장·관리·조회·분석하도록 최적화된 데이터베이스
  • 키워드: 시간축, 고속 Write, 시간 인덱스, 데이터 압축, Downsampling, Retention
  • 분류: 특수 DB
  • 핵심: 시간 중심 데이터 → 고속 수집 → 압축 저장 → 시간 범위 조회 → 시계열 분석
  • 특성:
    특성설명
    시간 종속성모든 데이터가 Timestamp를 가짐
    고빈도 발생짧은 주기로 지속적인 데이터 생성
    Append 중심기존 데이터 수정보다 신규 데이터 추가가 많음
    대용량장기간 축적 시 데이터 규모 급증
    순차성시간 순서에 따른 데이터 특성이 중요
    조회 패턴특정 시간 구간의 Range Query가 빈번
    상관성시간에 따른 추세·패턴 분석 필요
  • 5계층 구조:
    계층핵심 역할주요 기술
    ① 데이터 발생시계열 데이터 생성IoT, 센서, 서버
    ② 수집/전송대량 데이터 수집·전송Agent, Kafka, MQTT
    ③ 저장/관리시간순 저장 및 효율적 관리인덱스, 압축, Partition, WAL
    ④ 분석/질의시간 범위 조회·집계Range Query, Window, Downsampling
    ⑤ 서비스/시각화모니터링·분석 결과 제공API, Dashboard, Grafana
  • 주요 구성요소:
    구분핵심기술설명목적
    시계열시간 기반 인덱싱Timestamp 중심 인덱스 구성시간 조회 성능 향상
    시간 파티셔닝시간 구간별 데이터 분할대용량 관리·검색 최적화
    데이터 압축시간 순서 및 값의 특성을 활용한 압축저장공간 절감
    수명주기다운샘플링고해상도 데이터를 낮은 주기로 집계장기 보관 효율화
    TTL / Retention데이터 보존기간 자동 관리저장공간 관리
    연속 집계시간 구간별 통계 자동 생성분석 성능 향상
  • 인사이트: 단순히 시간 데이터를 저장하는 DB를 넘어, IoT·클라우드·AI 확산으로 증가하는 대규모 실시간 데이터를 고속 수집·압축·분석하기 위한 데이터 플랫폼으로 발전
