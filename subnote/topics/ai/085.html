[하위] 3-1. 루프 엔지니어링

  • 정의: AI 에이전트가 사람의 지속 개입 없이, 원하는 목표를 위해 피드백 루프를 설계/운영하는 방법론
  • 키워드: HOTL, Self-Evaluation, Exit Condition
  • 에이전트 루프 (Agent Loop) 동작 구조:
    프로세스설명핵심
    1. 목표/관찰해결해야 할 목표(Goal)를 수용함사용자 의도 및 최종 목적지
    2. 계획복잡한 태스크를 하위 단계로 분해 및 할당전체적인 실행 계획
    3. 판단(추론)LLM이 현재 상태를 분석하고 다음 행동 결정ReAct / CoT
    3. 행동(툴 호출)외부 도구(API, 코드, 검색 등)를 실행함외부 세계와의 상호작용
    4. 검증/기록도구 실행 결과를 확인하고 컨텍스트에 기록피드백 및 지식 반영
    5. 판단(종료 조건)목표 달성 여부를 확인하여 루프 지속 결정조건 미충족 시 추론 단계로 재순환
    6. 종료(결과 반환)최종 완성된 결과물을 사용자에게 전달태스크 완결 및 루프 종료
  • 구성요소:
    구분주요 기술핵심
    목표수립Task Decomposition목표 하위분해
    System Guardrails/Skills유해입력 차단
    추론·의사결정ReAct추론-행동 반복
    Plan-and-Solve동적 재계획
    실행·외부연동MCP/Plugins/Connectors도구 자율호출
    Worktrees작업 병렬 수행
    Sandbox격리 코드실행
    검증·환류Self-Evaluation자체 신뢰성검증
    Feedback LOOP오류 자동보정
    상태관리·종료Stateful Memory / Vector DB문맥상태 유지
    Exit Condition루프 종료조건
