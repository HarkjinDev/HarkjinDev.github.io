[하위] 3-1. 메타모픽 테스트 (Metamorphic Testing)

  • 정의: 입력의 특정 변형(메타모픽 관계)에 따른 출력의 변화 관련성을 검증하는 기법
  • 용도: 테스트 오라클(정답지)이 없는 경우 유용하게 활용
  • 구성요소:
    구분요소 및 유형설명 (15자 이내)
    구성 요소관계 정의수식 및 입출력 함수 정의
    관계 유형가법성 (Additivity)입력값 합산 시 출력값 변화
    승법성 (Multiplicativity)입력값 배수 시 출력값 변화
    순서 보존 (Order)입력 순서에 따른 결과 유지
    균등성 (Invariance)변형 후에도 출력 결과 동일
    부분집합 (Subset)부분 입력 시 결과 포함 관계
  • 테스트 수행절차:
    구분수행 절차설명
    ① 관계 정의테스트 대상 선정검증할 AI 기능 및 테스트 목적 선정
    Metamorphic Relation 정의입력 변화에 따른 예상 출력 관계 정의
    ② Source TestSource Input 생성원본 테스트 데이터 생성·선정
    Source Output 획득AI 시스템에 입력하여 기준 출력 획득
    ③ Follow-up TestInput Transformation변환 규칙에 따라 원본 입력 변환
    Follow-up Input 생성변환된 데이터를 AI 시스템에 입력
    ④ 관계 검증Follow-up Output 획득변환된 입력에 대한 출력 획득
    Metamorphic Relation 비교원본·변환 출력 간 정의된 관계 검증
    ⑤ 결함 분석Pass/Fail 판정관계 만족 시 정상, 위반 시 실패 판정
    원인 분석 및 개선관계 위반 원인 분석 및 모델 개선
  • 전통적 테스트와 메타모픽 테스트 비교:
    구분비교 항목전통적 테스트메타모픽 테스트
    테스트 관점검증 관점기대·실제 결과 비교입력 변환 전후 출력 관계 비교
    Test Oracle명확한 정답·기대 결과 필요정답 없이 Metamorphic Relation 활용
    테스트 입력개별 Test Input 사용Source·Follow-up Input 사용
    테스트 결과실제·기대 결과 일치 여부변환 전후 출력 관계 만족 여부
    결함 판정Expected·Actual Output 불일치Metamorphic Relation 위반
    검증 방식결과 기반(Result-based)관계 기반(Relation-based)
    수행·적용테스트 구성Input → Expected → ActualSource → 변환 → Follow-up → 관계 검증
    테스트 케이스입력별 기대 결과 작성Source·Follow-up Test 연계
    테스트 목적기능 정확성·요구사항 충족일관성·강건성·잠재 결함 검증
    적용 대상정답이 명확한 결정론적 시스템AI·ML 등 정답 산정이 어려운 시스템
    자동화기대 결과 기반 자동 판정관계 기반 자동 판정
    주요 한계정답 데이터·Oracle 확보 부담적절한 Metamorphic Relation 설계 필요
  • 인사이트: 메타모픽 테스트는 명확한 정답 산정이 어려운 AI·ML 시스템의 Test Oracle 문제를 완화하는 관계 기반 검증 기법으로, 전통적 테스트와 상호 보완적으로 활용 가능함. AI 시스템의 신뢰성 확보를 위해 적절한 메타모픽 관계 설계와 지속적·자동화된 검증 체계 구축이 중요함.
