7. 메타학습 (Meta Learning)

  • 정의: 메타 지식을 통해 새로운 문제를 적은 데이터와 적은 학습만으로 빠르게 적응하도록 하는 패러다임
  • 키워드: Learning to Learn, Few-shot Learning, MAML, MANN, Task Distribution, Base/Meta Learner, Support/Query Set
  • 분류: 비지도학습
  • 핵심 개념·원리:
    항목설명핵심
    Learning to Learn학습하는 방법 자체를 학습학습법 학습
    Few-shot 적응소량데이터로 신속히 새 과제 적응소량데이터 적응
    이중루프 구조Inner/Outer 루프로 과제별·전체 최적화이중루프 최적화
    일반화 능력다양한 과제 경험으로 범용성 확보범용 일반화
  • 구성요소·기술요소:
    구분기술요소설명핵심
    학습 대상Task Distribution다양한 관련 Task를 학습해 공통패턴·적응전략 도출공통패턴 도출
    학습 단계Meta-Training여러 Task 반복학습으로 메타지식·초기파라미터 학습메타지식 학습
    Meta-Testing새로운 Task에서 소량데이터로 빠르게 적응신속 적응
    학습 구조Base Learner개별 Task를 수행하는 모델(Inner Learning Loop)개별과제 수행
    Meta Learner / Meta KnowledgeBase Learner 결과 분석해 초기가중치·전략 최적화(Outer Loop)전략 최적화
    데이터 구성Support Set/Query SetSupport Set으로 적응, Query Set으로 테스트 진행적응·테스트셋
    최적화기반MAML초기파라미터·학습률 자체를 학습하는 메타최적화기법초기값 최적화
    메트릭기반Matching Network / Prototypical Network유사도 기반 Few-shot 분류 수행거리기반 분류
    모델기반MANN(Memory-Augmented NN)외부메모리·내부상태로 학습속도·업데이트 조절메모리기반 조절
  • 인사이트: 메타학습은 "학습하는 법을 학습"함으로써 데이터가 부족한 새로운 과제에도 신속히 적응하는 범용 지능의 핵심 기반기술이다.
