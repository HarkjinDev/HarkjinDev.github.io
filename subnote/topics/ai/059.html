[하위] 4-1. 리랭커 (Reranker)

  • 정의: 검색된 문서의 질의 관련성을 재평가하여 결과 순위를 최적화하는 기술
  • 키워드: 재순위화, 의미적 관련성, 교차 인코더, 이중 인코더, 검색 정확도, RAG
  • 분류: 생성형 AI/LLM
  • 리랭커 핵심 구성요소:
    구성요소주요 기능핵심
    질의 (Query)사용자 질문·검색 의도 입력검색 기준
    검색기 (Retriever)후보 문서 1차 검색후보 추출
    관련성 평가 (Scoring)질의·문서 관련성 점수 산출의미 분석
    재순위화 (Reranking)관련성 점수 기반 문서 정렬순위 최적화
    상위 문서 선정 (Top-K)고관련성 문서 선별컨텍스트 최적화
  • 리랭커 주요 기법:
    구분기법주요 원리핵심
    신경망 기반Cross-Encoder질의·문서를 함께 입력하여 관련성 평가정밀 재순위화
    LLM 기반 리랭킹LLM으로 문서 관련성 평가·순위 결정문맥 추론
    검색 융합RRF (Reciprocal Rank Fusion)복수 검색 결과의 순위를 결합순위 융합
    학습 기반Learning to Rank관련성 학습 데이터 기반 순위 예측순위 학습
    규칙 기반가중치 재순위화관련성·최신성·중요도 가중치 적용규칙 기반 정렬
  • 리랭커 수행 절차:
    단계수행 절차주요 활동핵심
    1. 질의 입력Query Processing사용자 질의 분석·정규화검색 의도
    2. 후보 검색Initial Retrieval벡터DB·BM25 기반 후보 문서 검색1차 검색
    3. 관련성 평가Relevance Scoring질의·문서 간 의미적 관련성 산출정밀 평가
    4. 재순위화Reranking관련성 점수 기반 순위 재정렬·Top-K 선정검색 최적화
    5. 답변 생성Generation선정된 문서를 LLM에 전달·응답 생성RAG 연계
  • 인사이트: RAG에서는 1차 검색의 Recall을 충분히 확보한 뒤 Cross-Encoder 기반 재순위화로 Precision을 개선하고, 후보 문서 수와 Top-K를 조정하여 응답 품질·지연시간·토큰 비용을 함께 최적화해야 함.
