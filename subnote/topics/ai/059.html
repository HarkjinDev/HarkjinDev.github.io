[하위] 4-1. LLM 환각(Hallucination)

  • 정의: 모델 학습·추론의 한계로 사실과 다른 정보를 사실처럼 확신해 생성하는 현상
  • LLM 환각 발생 원인:
    구분발생원인핵심
    데이터 요인학습 부족도메인 및 최신정보 부족
    데이터 노이즈거짓·오류정보 학습
    편향(Bias)편향된 데이터 학습
    모델 요인확률적 생성 특성그럴듯한 오답 생성
    긴 문맥 정보 손실중요 정보 왜곡 및 누락
    사용자 요인모호한 질의임의의 전제 보완
    복잡한 논리 요구추론 역량 한계 초과
  • LLM 환각 유형:
    유형항목사례
    내재적 환각모순 내용 생성입력된 근거 문서와 모순되는 내용 생성
    문맥 왜곡제공된 Context의 잘못된 해석 및 왜곡
    RAG 한계 오류RAG 근거가 존재함에도 오류 발생
    외재적 환각미학습 내용 생성입력 및 학습 지식에도 없는 내용 생성
    허위 사실 창작검증이 불가능한 새로운 사실 창작
    근거 부족근거 문서가 부족할 때 주로 발생
  • LLM 환각 해결 방안:
    구분해결방안핵심
    근거 강화근거 기반 생성 (RAG)문서 범위 내 답변 유도
    지식 그래프 (Knowledge Graph)엔티티 간 논리적 관계 제공
    생성 제어프롬프트 설계 기법형식 제한 및 단계적 사고
    디코딩 파라미터 최적화답변 생성의 무작위성 통제
    사후 검증Self-Consistency반복 생성 답변의 일치 확인
    검증 루프초안 스스로 점검 및 수정
    Human-in-the-loop (HITL)최종 판단 전 분석가 확인
