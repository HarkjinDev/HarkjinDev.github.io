12. MCP (Model Context Protocol)

  • 정의: AI모델과 외부도구·데이터소스를 표준화된 방식으로 연결하는 개방형 프로토콜
  • 키워드: Anthropic, Client-Server, JSON-RPC, Tool/Resource/Prompt, 상호운용성
  • 분류: 생성형 AI/LLM
  • 유형·분류(3대 프리미티브):
    항목설명핵심
    Tools(도구)AI가 호출가능한 함수·액션 제공실행가능 함수
    Resources(리소스)파일·DB 등 컨텍스트용 데이터 제공컨텍스트 데이터
    Prompts(프롬프트)재사용가능한 프롬프트 템플릿 제공템플릿 제공
  • 구성요소·기술요소:
    구분구성요소핵심 기술
    프로토콜계층JSON-RPC 2.0클라이언트-서버간 메시지 교환표준
    전송방식(Transport)STDIO(로컬), HTTP/SSE(원격) 지원
    아키텍처요소MCP HostClaude Desktop 등 AI애플리케이션(클라이언트 관리)
    MCP ClientHost 내 서버별 1:1 연결담당 커넥터
    MCP Server실제 도구·데이터를 노출하는 경량 프로그램
    보안·거버넌스권한관리(Permission)사용자승인 기반 도구실행 통제
    샌드박스 실행격리환경에서 안전한 도구실행
  • MCP 작업 실행 과정:
    단계주체 (송신자 → 수신자)동작 및 내용
    1Host → Client작업 요청
    2Client → Server메시지 전달
    3Server (내부 처리)요청 수행 (예: 파일 읽기, DB 조회 등)
    4Server → Client결과 회신
    5Client → Host사용자에게 결과 전달
  • 인사이트: MCP는 AI-도구간 연결을 "M×N" 문제에서 "M+N" 문제로 단순화한 개방형 표준으로, USB-C처럼 AI 생태계의 상호운용성을 견인하는 핵심 인프라로 자리잡고 있다.
