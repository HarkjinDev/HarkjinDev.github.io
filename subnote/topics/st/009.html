6. 데이터 노이즈(Noise, 데이터 잡음)

  • 정의: 데이터에 포함된 오류로 인해 실제 의미와 무관하게 발생한 불필요하거나 왜곡된 값
  • 키워드: 측정 오류, 입력 오류, 환경 오류, 왜곡값, 필터링, 평활화, 대체
  • 분류: 통계 기초
  • 주요 유형:
    구분설명예시
    측정 노이즈센서·측정 과정의 오차온도 25.1 → 125.1
    입력 노이즈사용자 입력 실수나이 35 → 350
    전송 노이즈전송 과정에서 발생한 오류데이터 일부 손상
    환경 노이즈외부 환경에 의한 데이터 왜곡센서 전자파 간섭
    라벨 노이즈잘못된 데이터 라벨정상 데이터를 공격으로 분류
  • 노이즈 처리 방법:
    방법핵심
    필터링불필요한 데이터 제거
    평활화(Smoothing)이동평균 등으로 변동 완화
    이상치 탐지통계·ML 기반 이상값 식별
    대체(Imputation)오류·결측값을 적절한 값으로 대체
    정규화/표준화데이터 범위 및 분포 정규화
