5. 데이터 이상치 (Outlier)

  • 정의: 데이터의 일반적 분포에서 크게 벗어난 비정상적 관측값
  • 키워드: 이상치, 전역/맥락/군집 이상치, IQR, Z-score, Boxplot, KNN, DBSCAN
  • 분류: 통계 기초
  • 주요 발생 원인: 데이터 오류, 측정 단위 불일치, 샘플링 오류, 비정상적 이벤트, 극단적인 행동
  • 유형 (3가지): <전맥군>
    • 전역 이상치(Global): 전체 데이터 관점에서 극단적으로 벗어난 값
    • 맥락 이상치(Contextual): 특정 맥락에서만 비정상 (시계열 계절성 등)
    • 군집 이상치(Collective): 개별로는 정상이나 집합 패턴이 비정상
  • 이상치/노이즈 탐지 방법:
    구분탐지 기법핵심 원리예시
    통계 기반Z-Score평균에서 벗어난 정도(표준편차) 측정|Z| > 3
    IQR(사분위수 범위)Q1~Q3 범위를 벗어난 값 탐지Q1-1.5IQR 미만
    시각화Box PlotQ1·Q3와 수염 범위를 이용해 이상치 식별IQR 시각화
    거리 기반k-NN주변 데이터와의 거리가 먼 값 탐지고립된 데이터
    밀도 기반LOF주변 대비 데이터 밀도가 낮은 값 탐지주변과 동떨어진 값
    군집 기반Clustering군집에서 벗어난 데이터 탐지군집 외부 데이터
    ML 기반Isolation Forest이상 데이터를 빠르게 분리고차원 데이터
    Autoencoder복원 오차가 큰 데이터 탐지비정상 패턴
  • 이상치 vs 노이즈 비교표:
    비교 항목이상치 (Outlier)노이즈 (Noise)
    개념드물게 나타나는 값무작위 발생 오류
    원인희귀 현상 또는 실수시스템 및 환경 오차
    가치새로운 정보 포함분석 방해 요소
    처리원인 파악 후 분석필터링 및 제거
    핵심발견할 주요 신호제거할 단순 잡음
  • 인사이트: 아웃라이어는 의미 있는 정보를 가질 수 있으나, 노이즈는 무작위 오차. 제거 전 원인 파악이 선행되어야 한다.
