1. 절차지향 프로그래밍 (Procedure Oriented Programming)

  • 정의: 프로그램을 순차적으로 실행되는 함수(프로시저)들의 집합으로 구성하는 프로그래밍 패러다임
  • 키워드: 함수, 프로시저, 순차 실행, 전역변수, C언어, 구조적 프로그래밍
  • 분류: 프로그래밍
  • OOP와 비교
    비교 항목절차지향 프로그래밍 (PP)객체지향 프로그래밍 (OOP)
    관점순서와 로직 (함수 중심)주체와 상호작용 (객체 중심)
    설계하향식 설계 (Top-Down)상향식 설계 (Bottom-Up)
    핵심기능 분해객체 조힙
    원칙구조적 프로그래밍 원칙SOLID 원칙
    코드 재사용함수 재호출클래스
    데이터 철저한 분리(전역변수)캡슐화
    흐름제어제어구조 단순화SOLID
    장점빠르고 직관적임, 상태 통제 중심, 전역 변수(상태) 최소화유연성 및 확장성 중심, 유지보수 및 재사용 우수
    적합 분야소형 프로젝트, 고성능 연산대규모 소프트웨어
    언어C, Pascal, FortranJava, C++, Python
  • 인사이트: 절차지향은 처리 흐름이 명확하고 성능이 높은 장점이 있어 임베디드·시스템 프로그래밍에 여전히 활용되며, OOP와의 장단점 비교가 주요 출제 포인트.
