19. 소프트웨어 테스트 자동화(Test Automation)

  • 정의: 테스트 케이스 실행·결과 검증·리포팅을 자동화 도구와 스크립트로 처리하여 반복 테스트의 효율성을 높이는 활동
  • 키워드: 테스트 자동화 도구, Selenium, JUnit, CI/CD 연동, ROI, 자동화 피라미드
  • 분류: 테스트
  • CI/CD 파이프라인 테스트 자동화:
    단계테스트 자동화 방안주요 테스트핵심
    코드 작성정적 분석 자동화Lint, SAST, 코드 품질결함 조기 발견
    Build빌드 시 테스트 수행Unit Test기능 단위 검증
    CI코드 통합 시 자동 테스트Integration Test모듈 연계 검증
    API·기능 자동 검증API Test, Functional Test기능 정상성 검증
    CI/CD보안 테스트 자동화SAST, DAST, SCA, IAST보안 취약점 검출
    Staging실제 환경 유사 테스트E2E, Regression Test전체 기능 검증
    배포 전품질 게이트 적용Coverage, 취약점, 성능배포 기준 충족
    배포 후운영 상태 자동 검증Smoke, Synthetic Test배포 이상 탐지
  • Shift-Left 테스트: 테스트·품질·보안 활동을 SDLC 좌측(요구·설계·구현 초기)으로 이동시켜 결함을 조기 에 예방·발견하는 전략
  • 인사이트: 자동화 피라미드는 단위 테스트 비중을 높이고 E2E 비중을 낮추는 구조를 지향하며, UI 테스트 과의존은 유지보수 비용 급증을 야기하는 안티패턴(아이스크림 콘).
