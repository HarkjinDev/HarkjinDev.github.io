14. 데이터 품질인증 (Data Quality Certification, DQ, 26.2.)

  • 정의: 데이터 내용과 관리체계의 품질 수준을 심사·평가하여 인증하는 제도
  • 키워드: 데이터 내용 인증, 데이터 관리체계 인증, 완전성, 유효성, 정확성, 품질등급, 성숙도
  • 분류: 가이드
  • 법적 근거: 「데이터 산업진흥 및 이용촉진에 관한 기본법」 제20조 및 동법 시행령 제20조의5
  • 데이터 품질인증의 인증 유형 및 인증 대상:
    인증 유형인증 대상주요 내용핵심
    데이터 내용정형데이터DB·테이블·CSV 등 데이터값·구조데이터 품질
    비정형데이터텍스트·이미지·영상·음성 등객체·메타데이터 품질
    데이터 관리체계데이터 기반 프로젝트데이터 생성·가공·활용 사업프로젝트 관리
    정보시스템데이터 처리 시스템·플랫폼시스템 관리
    관리조직데이터 운영 조직·부서·전사조직 관리
  • 데이터 품질인증의 품질기준:
    구분품질기준주요 내용핵심
    데이터 내용완전성필수 데이터·레코드의 누락 여부결측 방지
    유효성값의 형식·범위·업무규칙 준수규칙 적합성
    일관성데이터 간 참조·형식·표준 일치정합성
    정확성실제 값·메타데이터의 정확성오류 최소화
    접근성표준 형식·규약에 따른 접근 가능성활용 가능성
    유일성데이터·레코드의 중복 여부중복 방지
    데이터 관리체계품질기획 (QP)품질 목표·정책·계획 수립품질 계획
    품질통제 (QC)데이터 처리·품질 모니터링품질 통제
    품질보증 (QA)품질 측정·평가·검토품질 검증
    품질개선 (QI)오류 원인 분석·프로세스 개선지속 개선
  • 데이터 품질인증의 인증 등급:
    인증 유형인증 등급판정 기준인증 여부
    데이터 내용Class A품질 점수 99% 이상인증
    Class B품질 점수 97% 이상인증
    Class C품질 점수 95% 이상인증
    등급 미달품질 점수 95% 미만미인증
    데이터 관리체계Level 1 (기초적 관리)요구사항 관리·활동 증적 미흡미인증
    Level 2 (실무적 관리)요구사항·작업·품질 통제 수행인증
    Level 3 (체계적 관리)표준 프로세스 정의·적용인증
    Level 4 (정량적 관리)품질 성과 측정·정량적 통제인증
    Level 5 (관리 최적화)지속적 프로세스 혁신·개선인증
  • 데이터 내용 평가 유형:
    평가 유형구분 기준핵심
    Complex심사항목 적용 범위가 넓은 평가종합 평가
    Normal일반적인 심사항목 적용 평가일반 평가
    Simple심사항목 적용 범위가 제한된 평가간소 평가
