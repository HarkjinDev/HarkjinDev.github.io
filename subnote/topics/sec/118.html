14. 기밀 컴퓨팅 (Confidential Computing)

  • 정의: 데이터를 처리하는 중에도 하드웨어 기반 신뢰 실행 환경(TEE)에서 암호화·격리하여 클라우드·외부 위협으로부터 사용 중 데이터를 보호하는 기술
  • 키워드: Data in Use 보호, TEE, 신뢰 실행 환경, Intel SGX, AMD SEV, Enclave, 기밀 가상머신, 원격 증명
  • 분류: 특수 보안
  • 핵심 기술:
    구분구성요소핵심 기술
    Data저장 (At Rest)AES, TDE, 디스크 암호화
    전송 (In Transit)TLS, IPsec, mTLS
    사용 (In Use)TEE, Enclave, 기밀 VM
    TEE 구현Intel SGXEnclave 기반 애플리케이션 격리
    Intel TDX하드웨어 기반 VM 격리·보호
    AMD SEV-SNPVM 메모리 암호화·무결성 보호
    ARM TrustZone보안·일반 실행 환경 분리
    신뢰 실행Trusted OS신뢰 영역 내 애플리케이션 실행·관리
    Enclave코드·데이터의 격리 실행 영역
    검증·보호원격 증명 (Remote Attestation)TEE 실행 환경·무결성 검증
    봉인 (Sealing)TEE·정책에 결합된 데이터 암호화
    신뢰 근원 (Root of Trust)하드웨어 기반 신뢰 검증
    보안 지원Secure Boot부팅 단계 코드 무결성 검증
    HSM암호키 생성·보관·보호
    클라우드 구현기밀 VM (Confidential VM)하이퍼바이저로부터 VM 보호
    기밀 컨테이너 (Confidential Container)TEE 기반 컨테이너 워크로드 보호
  • 수행 절차:
    단계수행 절차주요 활동핵심
    1. 환경 생성TEE Provisioning격리 실행 환경·워크로드 생성안전한 실행
    2. 원격 증명Remote AttestationTEE 측정값·서명·신뢰 상태 검증신뢰성 확인
    3. 키 제공Secure Key Provisioning검증된 TEE에 암호키·비밀정보 전달키 접근통제
    4. 데이터 복호화Secure DecryptionTEE 내부에서 보호된 데이터 복호화기밀성 유지
    5. 안전한 연산Confidential Execution격리 환경에서 민감 데이터 연산사용 중 보호
    6. 종료·폐기Secure Termination민감정보·임시 키 제거 및 종료잔존정보 보호
  • 인사이트: 기밀 컴퓨팅은 "클라우드 사업자도 데이터를 볼 수 없다"는 제로 트러스트 원칙을 하드웨어 수준에서 구현하는 기술로, 의료·금융·AI 등 민감 데이터의 클라우드 이전 장벽을 낮추는 핵심 enabler로 부상하고 있으며 멀티파티 컴퓨팅·AI 모델 보호와 결합하여 프라이버시 보존 컴퓨팅의 핵심 인프라로 자리잡고 있음
