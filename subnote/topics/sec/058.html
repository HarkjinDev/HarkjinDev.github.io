2. 시큐어 코딩 (Secure Coding)

  • 정의: 보안 취약점을 예방하는 안전한 소프트웨어 코딩 기법
  • 키워드: 입력값 검증, SQL 인젝션 방지, XSS 방지
  • 분류: 시스템/SW 보안
  • 7대 보안 약점 분류 (행안부): <입보시에/코캡아>
    • 입력 데이터 검증 및 표현: SQL 인젝션, XSS, 버퍼 오버플로우
    • 보안 기능: 적절한 인증, 암호화 사용
    • 시간 및 상태: TOCTOU, 경쟁 조건
    • 에러 처리: 민감 정보 노출, 부적절한 예외 처리
    • 코드 품질: 사용되지 않는 코드, 복잡도
    • 캡슐화: 민감 데이터 노출
    • API 오용: 안전하지 않은 API 사용
  • SAST, DAST, IAST:
    구분SASTDASTIAST
    분석 방식정적 분석동적 분석대화형 분석
    테스트 유형White Box TestBlack Box TestGray Box Test
    수행 단계설계·개발 단계테스트·배포 단계테스트 단계
    분석 대상소스코드·바이너리실행 중인 애플리케이션실행 중 애플리케이션 + 내부 코드
    특징코드 기반 취약점 조기 발견외부 공격자 관점에서 취약점 탐지실행 중 코드 흐름을 추적하여 정밀 분석
    장점조기 발견, 높은 ROI실제 공격 관점, 전체 시스템 평가SAST+DAST 장점 결합, 낮은 오탐
    단점오탐, 실행환경 반영 한계미탐, 원인 분석 한계에이전트 필요, 성능 영향
    핵심 키워드코드 중심외부 공격 중심실행 코드 중심
  • 인사이트: SAST(정적 분석)와 DAST(동적 분석)를 CI/CD 파이프라인에 통합하여 자동화된 보안 검증 체계(DevSecOps)를 구축하는 것이 현대적 시큐어 코딩의 실천 방법임
