15. 에이전트 재킹 (Agent Jacking / AI Agent Hijacking)

  • 정의: 공격자가 AI 에이전트의 권한을 악용해 비인가 작업을 수행하도록 유도하는 AI 보안 공격
  • 키워드: Agent Hijacking, Agent Goal Hijack, Indirect Prompt Injection, Tool Poisoning, MCP, Memory Poisoning, Goal Manipulation, Privilege Abuse, Trust Boundary, Agentic AI, OWASP ASI01
  • 분류: AI 보안
  • 주요 공격 유형:
  • Prompt Injection·Tool Poisoning·Memory Poisoning은 Agent Jacking을 유발할 수 있는 공격 기법이며, Agent Jacking은 공격 결과인 목표·행동 탈취에 초점을 둠.
    공격 유형주요 공격 방식핵심
    프롬프트 인젝션 (Prompt Injection)외부 콘텐츠에 악성 지시 삽입지시 변조
    도구 포이즈닝 (Tool Poisoning)MCP 도구 설명·응답·메타데이터 조작도구 신뢰 악용
    메모리 포이즈닝 (Memory Poisoning)에이전트 기억·RAG 컨텍스트 오염지속적 행동 조작
    신원 위장 (Agent Spoofing)에이전트 간 메시지·발신자 위조신뢰 관계 악용
    권한 악용 (Privilege Abuse)에이전트의 기존 권한으로 비인가 작업 유도권한 오남용
  • 공격 절차:
    단계수행 절차주요 활동
    1. 환경 탐색Agent Reconnaissance도구·권한·입력 경로·신뢰 경계 파악
    2. 악성 지시 주입Payload Injection문서·웹페이지·도구 응답에 악성 지시 삽입
    3. 목표 주도권 탈취Goal Hijacking외부 데이터를 정상 지시로 오인하도록 유도
    4. 비인가 실행Unauthorized ExecutionAPI 호출·정보 유출·파일 변경 등 수행
    5. 결과 확인Attack Verification실행 결과 및 목표 이탈 여부 확인
  • 주요 보안 위협 및 대응:
    구분보안 위협대응 기술핵심
    신뢰 분리외부 데이터의 명령 승격Trust Boundary·지시/데이터 분리신뢰 경계
    권한 통제에이전트 권한 오남용Least Privilege·RBAC·ABAC최소 권한
    실행 검증악성 도구·API 호출Tool Gateway·Policy Engine실행 통제
    승인 관리고위험 작업 자동 실행Human-in-the-loop·JIT 승인인간 승인
    감사 추적악성 행위 탐지·추적 한계Agent ID·실행 로그·행동 모니터링책임 추적
  • 인사이트: 기존 프롬프트 인젝션이 주로 모델의 응답 조작에 초점을 둔다면, 에이전트 재킹은 정상 인증정보와 실행 권한을 이용한 다단계 비인가 행위로 확대될 수 있음.
