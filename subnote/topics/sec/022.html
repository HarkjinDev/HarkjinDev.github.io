10. MAC (Message Authentication Code, 메시지 인증)

  • 정의: 비밀키를 이용해 메시지 무결성과 송신자인증을 함께 보장하는 인증코드
  • 키워드: 비밀키, 무결성, 인증, 해시함수, 위변조 방지, CBC-MAC, HMAC, GMAC
  • 분류: 암호학
  • 동작 원리:
    • ① 송신자가 비밀키 K와 메시지 m으로 MAC 값 생성: MAC = h(K, m)
    • ② 수신자가 동일한 비밀키 K로 MAC 재계산 후 수신된 MAC과 비교
    • ③ 일치하면 메시지 무결성 및 출처 인증 확인
  • 제공 속성: <맥무인>
    • 무결성(Integrity) + 인증(Authentication)
    • 기밀성·부인방지는 제공하지 않음
  • 유형:
    유형설명예시
    CMAC(Cipher-based MAC)블록암호 기반, 가변길이 안전처리NIST SP800-38B, 금융권 표준
    NMAC(Nested MAC)두 개의 키로 해시함수를 중첩(Nested) 적용하는 구조HMAC 설계의 이론적 기반
    HMAC해시함수와 비밀키를 결합해 MAC생성JWT, TLS, API 인증
    GMACAES-GCM 기반 인증태그 생성TLS 1.3, IPSec
  • 인사이트: MAC은 비밀키를 공유한 당사자 간에만 유효하므로 제3자에 대한 부인방지는 불가능함. 부인방지가 필요한 경우 전자서명을 사용해야 함
