9. 클라우드 보안 (Cloud Security)

  • 정의: 클라우드 환경에서 데이터와 서비스를 보호하기 위한 보안 활동
  • 키워드: 데이터 보호, 접근제어, 가상화 보안, 공유 책임, CSPM, CWPP, CNAPP, CIEM, SASE
  • 분류: 특수 보안
  • 공유 책임 모델 (Shared Responsibility): <데애런인>
    영역IaaSPaaSSaaS
    데이터고객고객고객
    애플리케이션고객고객CSP
    런타임고객CSPCSP
    인프라CSPCSPCSP
  • CNAPP(클라우드 네이티브 보안 플랫폼) 3대 핵심 요소:
    구분보호대상주요 기능
    CSPM설정·형상설정 오류 지속 탐지, 규정 준수 여부 모니터링
    CWPP워크로드런타임 위협 방어, 워크로드 취약점 스캔
    CIEM권한·자격과도한 접근 권한 탐지, 최소 권한 원칙 적용
  • SASE: SD-WAN과 클라우드 보안 엣지(SSE)를 단일 서비스로 통합 제공하여, 백홀 없이 정체성 기반으로 접속을 통제하는 보안 아키텍처
    영역구분설명 핵심
    NW(NaaS)SD-WAN소프트웨어 정의 기반 네트워크지능형 트래픽 관리
    보안 서비스(SSE)SWG웹 접속 보안 및 악성코드 차단안전한 웹 탐색
    CASB클라우드 앱 가시성 및 통제클라우드 통제
    ZTNA신원 기반의 엄격한 접근 제어제로 트러스트
    FWaaS클라우드 기반 차세대 방화벽클라우드 방화벽
  • 도입 시 보안 요소: 데이터 암호화, 접근제어(IAM), 가상화 보안, 로그 관리, 규정 준수
  • 인사이트: 클라우드 보안 사고의 대부분은 CSP 인프라가 아닌 고객의 잘못된 설정(Misconfiguration)에서 발생하므로, CSPM(Cloud Security Posture Management) 도입이 필수임
