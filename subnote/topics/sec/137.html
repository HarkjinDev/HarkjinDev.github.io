16. 멤버십 추론 공격 (Membership Inference Attack, MIA)

  • 정의: 특정 데이터가 머신 모델의 학습 데이터셋에 포함되었는지 추론하는 AI 프라이버시 침해 공격
  • 키워드: Membership Inference, MIA, Shadow Model, Attack Model, Confidence Score, Prediction Loss, Overfitting, Black-box, White-box, Differential Privacy, LiRA
  • 분류: AI 보안
  • 주요 유형:
    구분공격 유형공격 방식핵심
    Black-box신뢰도 기반 공격예측 확률·신뢰도 차이 분석출력 신뢰도
    손실값 기반 공격예측 손실값과 임계값 비교Loss Threshold
    레이블 기반 공격최종 예측 레이블·결정경계 특성 분석Label-only
    White-box기울기 기반 공격모델 내부 Gradient·Loss 분석내부 정보
    파라미터 기반 공격가중치·중간 활성화 정보 활용모델 접근
    모델 기반Shadow Model Attack유사 모델 학습 후 멤버십 분류그림자 모델
    LiRA멤버·비멤버 손실 분포의 우도비 분석통계적 추론
  • 공격 수행 절차:
    단계수행 절차주요 활동
    1. 정보 수집Target Model 분석모델 입력·출력 형식 및 접근 범위 파악
    2. 그림자 모델 생성Shadow Model Training대상 모델과 유사한 모델·데이터 구성
    3. 공격 모델 학습Attack Model Training멤버·비멤버 출력 특성 학습
    4. 대상 모델 질의Target Query특정 데이터 입력 후 예측 결과 수집
    5. 멤버십 추론Membership Decision학습 데이터 포함 여부 판정
  • 멤버십 추론·모델 역전·모델 추출 공격 비교:
    구분멤버십 추론 (MIA)모델 역전 (Inversion)모델 추출 (Extraction)
    목적학습 데이터 포함 여부 추론학습 데이터 특성·정보 복원모델 기능·동작 복제
    공격 대상학습 데이터 멤버십민감한 데이터 특성모델 구조·동작
    활용 정보예측값·신뢰도·손실값출력·기울기·모델 정보API 응답·입출력
    공격 결과Member/Non-member 판정데이터 특성·원본 일부 추정대체 모델 구축
    주요 위협개인정보 존재 여부 노출민감정보 유출모델 지식재산 침해
  • 공격 대응 방안:
    구분대응 기술주요 내용핵심
    차등 프라이버시DP-SGD학습 과정에 노이즈·기울기 제한 적용개인정보 보호
    정규화Dropout, Weight Decay과적합 완화·일반화 성능 개선과적합 방지
    규제적 학습Early Stopping검증 성능 기반 학습 조기 종료일반화 확보
    출력 제한Confidence Masking예측 확률·신뢰도 노출 제한정보 노출 축소
    보안 검증Privacy AuditingMIA 모의 공격·프라이버시 위험 평가공격 저항성
  • 인사이트: 과적합 모델과 과도한 예측정보 노출 환경에서 위험이 증가하며, 모델 출력 제한만으로는 근본적 방어가 어려움. 따라서 차등 프라이버시 기반 학습, 일반화 성능 개선, 출력정보 최소화 및 MIA 기반 프라이버시 감사를 결합한 다층적 보호체계 구축이 중요함. 합성데이터 생성·활용 환경에서도 원본 데이터의 멤버십 노출 여부를 평가하여 합성데이터의 안전성을 검증할 필요가 있음.
