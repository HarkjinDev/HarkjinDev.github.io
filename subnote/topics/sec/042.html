8. 비인간 신원 (Non-Human Identity, NHI)

  • 정의: 사람의 직접적인 개입 없이 자원에 접근하거나 상호 통신할 수 있도록 부여된 디지털 신원
  • 키워드: NHI, Machine Identity, Service Account, Workload Identity, AI Agent Identity, IAM, Secrets Management, Zero Trust, Least Privilege, SPIFFE/SPIRE, OAuth 2.0, mTLS
  • 분류: 인증/신원관리
  • 주요 유형:
    유형주요 대상설명
    서비스 계정 (Service Account)DB·백엔드·배치서비스 간 접근을 위한 전용 계정
    워크로드 신원 (Workload Identity)컨테이너·VM·서버리스실행 중인 워크로드의 신원
    기기 신원 (Device Identity)IoT·서버·네트워크 장비장치별 인증서·고유 신원 부여
    애플리케이션 신원 (Application Identity)API·SaaS·애플리케이션애플리케이션 간 접근권한 관리
    AI 에이전트 신원 (Agent Identity)AI Agent·자동화 봇자율적 작업·도구 실행 주체 식별
  • 핵심 구성요소:
    구성요소주요 기능핵심
    신원 식별 (Identification)비인간 주체별 고유 ID 부여고유 신원
    신원 인증 (Authentication)인증서·토큰·키 기반 신원 검증신뢰성 검증
    권한 관리 (Authorization)역할·속성 기반 접근권한 통제최소 권한
    자격증명 관리 (Secrets)키·인증서·토큰 발급·보관·교체자격 보호
    감사 추적 (Audit)신원별 접근·실행·변경 이력 기록책임 추적
    생명주기 관리 (Lifecycle)등록·변경·회수·폐기 자동화신원 거버넌스
  • NHI 주요 인증·관리 기술:
    기술주요 기능핵심
    API KeyAPI 호출 주체 식별·인증API 인증
    OAuth 2.0범위 제한 토큰 기반 접근 인가토큰 인가
    OIDC토큰 기반 인증·신원 확인신원 연합
    mTLS클라이언트·서버 상호 인증상호 인증
    SPIFFE/SPIRE워크로드 신원 표준화·자동 발급워크로드 인증
    PKI/X.509인증서 발급·검증·폐기인증서 기반 신뢰
    Secrets Manager키·토큰·비밀번호 보관·교체자격증명 보호
    PAM특권 신원·권한·세션 통제특권 접근관리
  • OWASP NHI Top 10 (2025) 보안 위협 및 대응:
    구분보안 위협주요 위험대응 방안
    NHI1부적절한 신원 폐기유휴 신원·권한 잔존자동 폐기·권한 회수
    NHI2비밀정보 유출API Key·토큰 노출Secret Scan·Vault
    NHI3취약한 서드파티 NHI외부 연동 경로 침해공급망 검증·권한 제한
    NHI4취약한 인증약한 인증수단 악용강력한 인증·mTLS
    NHI5과도한 권한권한 탈취 시 피해 확대최소 권한·JIT

    NHI7장기 유효 자격증명탈취된 인증정보 장기 악용단기 토큰·자동 교체
    NHI8환경 격리 미흡개발·운영 환경 간 침해 확산환경별 신원 분리
    NHI9NHI 재사용신원 공유로 침해 범위 확대서비스별 고유 신원
    NHI10인간의 NHI 사용행위 주체 추적·책임성 저하개인 계정 사용·접근통제
  • NHI 도입 시 고려사항:
    구분주요 한계대응 방안핵심
    신원 가시성미관리 서비스 계정·Shadow NHI신원 자동 탐색·인벤토리가시성 확보
    자격증명하드코딩·장기 유효 SecretVault·단기 토큰비밀정보 보호
    권한 관리서비스 계정 과권한RBAC·ABAC·최소 권한권한 최소화
    생명주기유휴 계정·폐기 누락자동 발급·교체·폐기자동화
    운영 안정성자격증명 교체 시 서비스 장애단계적 교체·무중단 적용가용성 확보
    감사 추적공유 계정으로 행위 추적 곤란고유 ID·중앙 감사로그책임성 확보
  • 인사이트: NHI는 클라우드·마이크로서비스·AI 에이전트 확산으로 증가하는 비인간 실행 주체의 신뢰성을 보장하는 IAM 핵심 기술임. 신원 자동 탐색·최소 권한·단기 자격증명·생명주기 자동화를 통합한 Zero Trust 기반 관리체계가 요구됨
