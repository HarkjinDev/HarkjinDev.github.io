Atomic Red Team 기법을 배치 자동 실행하고, Wazuh 기본 룰이 각 기법을 어떻게 처리하는지(정확 탐지 / 오분류 / 부수 로그만 / 미탐) 판정·집계했다.

판정 분포

공격은 실행됐으나 "대상 기법으로 탐지"됐는지가 핵심 기준.

정확탐지 오분류 부수 로그만(대상 미탐) 실행실패

전술별 탐지율

이 프로젝트의 핵심 발견. 기본 룰셋이 어느 전술을 잡고 어디에 공백이 있는가.

핵심 결론

탐지는 PowerShell에 편중

광범위한 탐지 공백

오분류는 소수 태그로 수렴

오분류 편향

대상 기법이 아닌 다른 기법으로 잘못 분류될 때, 어떤 태그로 수렴하는가.

Sigma 작성 대상

ANCILLARY(실행되나 대상 미탐)로 판정된 기법 = 커스텀 탐지 룰이 필요한 공백.

방법

① filter_windows_tests.py — 전체 저장소에서 Windows 실행가능 테스트 선별 (위험/hang 유발 기법 T1003·LSASS·시스템콜 등은 제외) ② batch_test.py — 선별 목록을 자동 실행 → 판정 → 재개/재실행 지원 ③ analyze_coverage.py — 전술별 커버리지·편향·Sigma대상 집계 판정: 공격 실행 부수 로그(T1059 등)는 ANCILLARY로 분리, 권한/차단 실패는 EXEC_FAILED로 분리해 실제 탐지결과만 측정
